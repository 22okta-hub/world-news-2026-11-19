The original editorial illustration was created for this entry. No news photographs, logos, official art, or recognizable political likenesses are used. Reporting facts are listed in [sources.md](sources.md).

## Run

The program uses only Python's standard library. It copies the bundled JPEG bytes to the required `/output/entry.png` path; the grader detects the image format from its file signature.

```sh
MAKEFUN_OUTPUT_DIR=out python main.py
```
